## 第一章 向量空间

### 1.1 线性无关

**定义**：向量组 v₁…vₙ 线性无关，指 k₁v₁+…+kₙvₙ=0 只有零解 k₁=…=kₙ=0 [§1.1]

**公式** [§1.1]

```
k₁v₁ + k₂v₂ + … + kₙvₙ = 0  ⟹  k₁ = k₂ = … = kₙ = 0
```

**例**：在 ℝ² 里判断 (1,0) 与 (0,1) 是否线性无关：设 k₁(1,0)+k₂(0,1)=(0,0)，得 k₁=0 且 k₂=0 [§1.1]

验算：把 k₁=0、k₂=0 代回左边，0·(1,0)+0·(0,1)=(0,0)，与等式右边一致，且这是唯一解

**适用**：判断对象必须是同一个向量空间里的向量组；零向量单独出现时，含它的组一定线性相关 [§1.1]

**常见误解**：把"两两不平行"当成线性无关。三个向量两两不平行仍可能共面而相关（推断，非原文）

### 1.2 基与维数

**定义**：向量空间的一组基是既线性无关、又能张成整个空间的向量组；基所含向量个数称为维数 [§1.2]

**公式** [§1.1]

```
dim V = 基中向量的个数 = 极大线性无关组的规模
```

**例**：ℝ³ 的标准基 e₁,e₂,e₃ 有 3 个向量，所以 dim ℝ³=3；换成 (1,1,0),(0,1,1),(1,0,1) 也是 3 [§1.2]

验算：解 k₁(1,1,0)+k₂(0,1,1)+k₃(1,0,1)=(0,0,0)，得方程组 k₁+k₃=0、k₁+k₂=0、k₂+k₃=0，三式相加得 2(k₁+k₂+k₃)=0，代回逐式解得 k₁=k₂=k₃=0

**适用**：维数由空间本身决定，与选哪组基无关；但"向量个数等于维数"只在组内无关时才等价于基 [§1.2]

**常见误解**：以为个数够多就是基。多一个就必然相关，此时只张成不独立（推断，非原文）

## 第二章 线性变换

### 2.1 线性变换的定义

**定义**：映射 T:V→W 是线性变换，指对任意 u,v 与标量 c 都满足 T(u+v)=T(u)+T(v) 且 T(cv)=cT(v) [§2.1]

**公式** [§2.1]

```
T(αu + βv) = αT(u) + βT(v)
```

**例**：T(x,y)=(2x, y) 是线性的；T(x,y)=(x+1, y) 不是，因为 T(0,0)=(1,0)≠(0,0) [§2.1]

验算：取 u=(1,0)、v=(0,1)、α=2、β=3，左边 T(2,3)=(4,3)，右边 2T(1,0)+3T(0,1)=(4,0)+(0,3)=(4,3)，两边相等

**适用**：定义域与陪域必须是同一数域上的向量空间；平移变换一律不是线性变换 [§2.1]

**常见误解**：把"图像是直线"当成线性。线性指的是保加法与数乘，不是图像形状（推断，非原文）

### 2.2 矩阵表示

**定义**：给定基之后，每个线性变换都唯一对应一个矩阵，第 j 列是 T 作用在第 j 个基向量上的像的坐标 [§2.2]

**公式** [§2.2]

```
T(x) = A x,   A 的第 j 列 = [T(eⱼ)] 在该基下的坐标
```

**例**：T(x,y)=(2x, y) 在标准基下的矩阵是 [[2,0],[0,1]] [§2.2]

验算：把 A 乘 (3,4) 得 (2·3+0·4, 0·3+1·4)=(6,4)，与 T(3,4)=(6,4) 一致

**适用**：换一组基，矩阵会变（相似变换），但行列式与特征值不变 [§2.2]

**常见误解**：以为变换和矩阵是同一个东西。变换是几何动作，矩阵是它在某组基下的记账方式（推断，非原文）

## 概念对照表

以下对照均据 [§1.1–§2.2] 整理，不是新增结论。

| | 线性无关 | 张成 |
|---|---|---|
| 判据 | 只有全零系数才得到零向量 | 空间里每个向量都能写成它们的组合 |
| 几何意义 | 互不重叠、没有冗余 | 覆盖面足够大 |
| 缺一边会怎样 | 只无关不张成：基不够用 | 只张成不无关：有冗余，不唯一 |

| | 特征值 | 奇异值 |
|---|---|---|
| 存在条件 | 只对方阵 | 任意矩阵 |
| 可能为负 | 可以 | 不可以 |

## 闭卷三题

1. 若一个向量组的向量个数超过空间维数，它能不能作为基？说明理由。
2. 为什么平移变换不是线性变换？用定义里的哪一条否掉它？
3. 同一个线性变换在两组合不同的基下得到的两个矩阵，什么量一定相同？

<details>
<summary>答案</summary>

1. 不能。超过维数必然线性相关（推断，非原文），而基要求无关 [§1.2]
2. 违反 T(0)=0：T(0,0) 在平移下不为零，故不满足保数乘 [§2.1]
3. 行列式与特征值（以及秩、迹）[§2.2]

</details>
