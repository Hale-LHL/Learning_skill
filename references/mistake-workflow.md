# 错题工作流 —— 归因决定一切

> 核心命题：**「这道题算错了」是零信息量的描述。**
> 同一个"算错了"，可能是知识缺口、概念误解、读题错误、或手滑。这四种的处理方式不但不同，有时**完全相反**——粗心加练量就是纯浪费，误解加练量会固化错误。

---

## 0. 四步主干

```
收集 → 归因 → 补漏 → 验证 → 入库
        ↑ 这一步决定后面三步怎么做
```

**禁止跳步**：拿到错题直接讲正确解法，是最常见的失败模式——你讲的是"正确答案应该长什么样"，用户学到的是"我的思路在哪一步偏了"吗？大概率没有。

---

## 1. 收集（30 秒，别拖）

需要拿到三样东西，缺一样就问：

| 要素 | 为什么要 |
|---|---|
| 题目原文 | 缺了没法判断是不是表征错误 |
| **用户的原始解法**（含草稿、涂改） | 这是唯一能反推思维路径的证据，比"我算错了"有用一百倍 |
| 用户的自我判断（"我觉得是算错了"） | 用来对比实际归因，暴露元认知偏差 |

> 用户只给题不给解法时：「先把你当时怎么想的写出来，哪怕是错的、写到一半的。**我要看的是路径，不是结果。**」

---

## 2. 归因（七类，定主因 + 次因）

一次错题通常有 1 个主因、0–2 个次因。**主因决定补漏方式，次因决定复习间隔。**

| 代号 | 类型 | 识别信号 | 追问话术 |
|---|---|---|---|
| **K** | 知识缺口 | 完全不知道该用什么方法/公式；问"这考的是哪一章" | 「这题涉及的那个定理，你现在能写出它的条件吗？」 |
| **M** | 概念误解 | 用得出来，但方向错了；自信且错得一致（不是随机错） | 「你为什么觉得应该这样？说理由。」→ 理由是自洽的错 = 误解 |
| **P** | 程序错误 | 方法对、思路对，中间某步骤顺序/符号/运算崩了 | 「从哪一步开始和标准解法分岔？」 |
| **R** | 表征错误 | 读错条件、漏看"不"字、单位混用、图表看错、把"至少"当"至多" | 「把题干里的限制条件逐条圈出来给我。」 |
| **C** | 粗心 | 会做、思路全对，纯手滑/抄错/漏步骤 | 「同样的题换个数字，你现在能做对吗？」（能 → 粗心） |
| **T** | 迁移失败 | 原题会做，换个问法/换个情境就不会 | 「这题和上周那道，你觉得哪里一样、哪里不一样？」 |
| **E** | 元认知 | 交卷时以为对了；不检查；时间分配崩；跳步不验算 | 「你做完有没有回头验？当时觉得自己对几成？」 |

### 归因判定的三个关键分辨

**① M（误解）vs C（粗心）**
> 换数字重做一次。做对 → C；还是错同一个地方 → M。
> **这条分辨极其重要**：把误解当粗心处理，会让你刷一百道同类题，稳固地把错误练成肌肉记忆。

**② K（缺口）vs T（迁移）**
> 问原题。原题会 → T；原题也不会 → K。
> K 要补知识，T 要练变式。给 K 的人刷变式题是折磨。

**③ P（程序）vs R（表征）**
> 让用户复述题干条件。复述错了 → R；条件复述对但步骤错 → P。

## 3. 补漏（按错因分派，方式不可互换）

| 主因 | 补漏方式 | **绝对不要做** |
|---|---|---|
| **K** 知识缺口 | 回到知识点本身，走最小示范 → 复述 → 一个基础题 | 讲这道错题（他会了这题，还是不会那章） |
| **M** 概念误解 | **先破后立**：让用户把错误模型完整讲出来 → 找一个它必然导致的荒谬结论 → 用户自己发现矛盾 → 再重建 | 直接说"你错了，应该这样"（错误模型会存活） |
| **P** 程序错误 | 拆步骤，逐步复现，定位崩的那一步，重练该步 3 遍 | 重做整题（崩的那一步练不到） |
| **R** 表征错误 | 训练"条件圈画"流程：每道题先列出全部限制条件再动笔 | 讲知识点（他不是不会，是没看见） |
| **C** 粗心 | 加**检查流程**（不是加题量）：固定验算项、单位核对、极端值代入 | 刷更多题（会做的题刷一百遍不产生收益） |
| **T** 迁移失败 | 给 3 道**表面不同、结构相同**的题；追问"它们的共同结构是什么" | 再刷同型题（他已经会了） |
| **E** 元认知 | 引入自评-实测对账：先自评几成把握，再闭卷做，对比差距 | 讲题（他不是不会做，是不知道自己不会） |

### M 类的"先破后立"具体怎么做

这是七类里最容易做错的一类。标准动作：

1. 「你把你的理解完整讲一遍，我要听你的逻辑。」（不打断）
2. 「按你这个理解，那 [构造一个该模型必然推出的荒谬结论] 也应该成立，对吗？」
3. 等他自己说"不对啊"。
4. 只有他自己发现矛盾之后，才给正确模型。
5. 给完必须要求：「现在用你的话讲一遍新模型，并说清它和你原来想法差在哪。」

> 跳过第 2–3 步直接纠正，错误模型不会被删除，只会被压制——下次考试压力一大就冒出来。

## 4. 验证（不是重做原题）

**验证必须用变式**，且变式要变在"表面特征"上，不改结构：

- 换数字、换情境、换问法方向（求 A 改成已知 A 求 B）
- 增加一个干扰条件
- 让错误答案"看起来更对"（放入常见陷阱选项）

**题目来源优先级**（这条防自嗨，很重要）：

1. 教材课后题 / 往年卷 / 课程习题册 —— **优先，因为它们是外部锚点**
2. 我按同结构改写的变式 —— 次选，且必须注明"这是我改的"
3. 我完全自己编的题 —— 最后手段，必须注明"这是我编的，难度可能不准"

原因：出题、判卷、评分全在同一个对话里完成时，这套系统没有任何外部校验。自己编的题会不知不觉向"用户已经会的方向"漂移，让人在假难度上通过。**用真题是你唯一能对抗这件事的手段。**

判定标准：
- 变式做对 → 确认修复
- 变式做错 → **归因错了，回到 §2 重新判**（最常见的原因：把 M 判成了 P）

**禁止用原题验证。** 原题做过一遍，短期记忆还在，做对不能说明任何问题。

## 5. 入库（写入 `~/.study-os/`）

```bash
python scripts/mistake.py add
```

交互式采集：题目、错解、主因、次因、变式结果。写两份东西：

1. `mistakes/index.json` 追加一条记录
2. `cards/cards.json` 生成 2 张检索卡：
   - 卡 1：考点本身（"X 定理的成立条件是什么"）
   - 卡 2：**错因触发卡**（"看到 [这题的特征]，第一步该做什么"）—— 这张比卡 1 重要，它训练的是识别

### SM-2 初始间隔（按错因差异化）

| 主因 | 首次间隔 | 理由 |
|---|---|---|
| K | 1 天 | 刚补的知识，需要快速巩固 |
| M | 2 天 | 重建的模型需要时间稳定 |
| P | 1 天 | 程序性记忆靠短间隔重复 |
| R | 3 天 | 是习惯问题，间隔太短会变成疲劳 |
| C | 7 天 | 不需要密集复习，只需偶尔提醒 |
| T | 4 天 | 迁移需要时间间隔才有意义 |
| E | 7 天 | 元认知靠周期性对账，不靠高频 |

## 6. 错误画像（最有行动价值的输出）

```bash
python scripts/mistake.py stats
```

输出示例：

```
总错题：23    近 30 天：11

错因分布：
  M 概念误解   ████████ 7  (30%)
  C 粗心       █████ 5  (22%)
  K 知识缺口   ████ 4  (17%)
  R 表征错误   ███ 3
  T 迁移失败   ██ 2
  P 程序错误   █ 1
  E 元认知     █ 1

⚠️ M 类占比最高。这类错误刷题无效，必须走"先破后立"。
⚠️ C 类 5 道里 4 道集中在「单位换算」→ 建议加一条固定检查项。
```

**怎么用**：错因分布告诉你该改什么习惯，而不是该刷多少题。

- M 占首位 → 你的问题不是练得少，是**理解有系统偏差**，去重读教材而不是刷题
- C 占首位 → 加检查流程，不加题量
- K 分布分散 → 是学习进度问题，正常
- K 集中在某一章 → 那章没学，去补
- T 占首位 → 练的都是同型题，缺变式

## 7. 反模式清单

| 反模式 | 为什么有害 |
|---|---|
| 拿到错题直接讲正确解法 | 用户学到"正确答案长什么样"，没学到"我的思路错在哪" |
| 不收集原始解法 | 没有思维路径证据，归因只能靠猜 |
| 主因判成"粗心"就结束 | 粗心是掩盖其他六类的垃圾桶标签。**判 C 必须通过"换数字重做"检验** |
| 用原题验证 | 短期记忆干扰，做对无意义 |
| 同类题刷 10 道 | 交错练习（g=0.42）优于集中练习，10 道同类不如 3 道混合 |
| 只统计"错了几道" | 数量无行动价值，分布才有 |
